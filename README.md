# AniMori — приложение для AniList

**Настольный клиент [AniList](https://anilist.co) для Windows со своим интерфейсом: списки, поиск, страницы тайтлов и студий, встроенный плеер. Всё на русском, без браузера и менеджера скриптов.**

**AniMori** — отдельная программа, которая работает с AniList напрямую. Она сама загружает данные, сама отрисовывает экраны и подставляет русские названия и описания из Shikimori и anime365.

Десктопная версия 2.x была устроена по-другому: это было окно с сайтом `anilist.co`, в которое встраивался тот же юзерскрипт. От этого подхода отказались, потому что полноэкранный режим, управление фокусом и оформление внутри чужой страницы нам не подчинялись. Версия 3.0 целиком построена на собственном интерфейсе.

AniMori — неофициальный проект, он не связан с командой AniList.

> [!NOTE]
> **Что где лежит.** У проекта три продукта в трёх репозиториях:<br>
> — **`Animori-Desktop`** (этот) — настольное приложение, теги вида `app-3.0.0`;<br>
> — **`Animori-Script`** — юзерскрипт для Tampermonkey, теги вида `script-2.2.0`;<br>
> — **`Animori-TV`** — приложение для Android TV, APK лежат в релизах.<br>
> В этом репозитории одна ветка — `main`. Кроме приложения, в ней лежат замороженная копия словаря перевода (для уже установленных копий скрипта) и workflow, который следит за обновлениями датасета.

## Состояние

Текущая версия — 3.0.1. В разделе [Releases](https://github.com/foulnike/Animori-Desktop/releases) есть установщик, портативный архив и манифест обновлений.

Гибридная версия 2.0.2 больше не поддерживается и удалена из рабочих веток. Установленные копии обновились до 3.0 автоматически: идентификатор программы (`com.foulnike.animori`), ключ подписи и адрес манифеста обновлений не изменились. Поэтому тег `app-3.0.0` стал последним релизом, и встроенное обновление старой версии предложило его установить. Настройки и токен хранятся в том же профиле, и новая версия их подхватывает. Подробнее — в [`docs/REPO-LAYOUT.md`](docs/REPO-LAYOUT.md).

## Что уже есть

В меню пять разделов: **Главная**, **Моё**, **История**, **Поиск** и **Настройки**. Остальные экраны открываются из них: **Аниме** — из списков и поиска, **Студия** — по ссылке на студию в карточке тайтла, **Просмотр** — кнопкой «Смотреть».

- **Всё на русском.** Интерфейс написан на русском. Названия и описания загружаются из Shikimori или anime365 с указанием источника. Часть названий уже есть во встроенном датасете, поэтому они видны даже без интернета.
- **Списки открываются сразу.** Коллекция хранится в локальной копии: она открывается мгновенно, работает без интернета и не пропадает после выхода из аккаунта.
- **Список остаётся у вас.** Можно импортировать список из AniList и Shikimori (с объединением или заменой), загрузить файл экспорта MyAnimeList (такой же XML выдаёт и Shikimori), экспортировать список в XML (его принимают Shikimori, AniList и Kitsu) и сохранить копию в облако. Сейчас поддерживается Яндекс Диск. Изменения на сервер AniList не отправляются. Подробнее — в [`docs/STORAGE.md`](docs/STORAGE.md).
- **Встроенный плеер.** Отдельный экран, который играет видео по прямым ссылкам, без чужого плеера и его рекламы. Источников два: Aniliberty и Kodik. Видео можно вынести в маленькое окно поверх других программ или транслировать на телевизор. Подробнее — в [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).
- **Страница тайтла.** Описание и названия на русском, персонажи и создатели с русскими именами, у студий — отдельный экран. Кадры и трейлер показаны сеткой, опенинги и эндинги из AnimeThemes играют на панели внизу окна.
- **Календарь выхода серий.** На главной, сразу под шапкой: когда выйдут новые серии того, что вы смотрите.
- **История.** Всё, что вы смотрели, от новых к старым. Продолжить просмотр можно в один клик.
- **Поиск на русском.** По названиям тайтлов, персонажам и создателям.
- **Запросы идут из самой программы.** К API обращается процесс приложения на Rust, а не веб-интерфейс. Поэтому ограничения CORS не мешают, а заголовки запросов полностью под контролем.
- **Прокси.** Прокси из настроек применяется к окну при запуске. В настройках видно результат проверки прокси и тестового запроса через него. Приложение предупреждает, что для применения настройки нужен перезапуск.
- **Вход в AniList.** Выполняется в отдельном окне. Токен хранится в программе и никуда не передаётся.
- **Автообновление.** При запуске программа проверяет последний релиз, сверяет цифровую подпись пакета, устанавливает обновление и перезапускается.
- **Окно приложения.** Внешние ссылки открываются в браузере по умолчанию, окно можно перезагрузить кнопкой в шапке. Полноэкранный режим программа поддерживает, но кнопки для него в интерфейсе пока нет.

## Чего здесь нет

| Чего нет | Почему |
| :--- | :--- |
| Перевода интерфейса через словарь | у приложения собственный интерфейс; `dictionary.json` нужен только юзерскрипту |
| Отправки изменений в AniList | синхронизация односторонняя, выгрузить список можно файлом или копией в облако |
| Блокировщика рекламы | он был нужен, только пока приложение показывало чужой сайт, и удалён вместе с ним |
| Манги | убрана из приложения |
| Юзерскрипта и режимов сборки | у приложения одна конфигурация сборки, без режимов — [`docs/REPO-LAYOUT.md`](docs/REPO-LAYOUT.md) |

## Требования

Windows 10 или 11 и компонент **WebView2**. В Windows 11 и обновлённой Windows 10 он уже установлен. Если его нет, установщик предложит его скачать.

## Сборка из исходников

Нужны Node.js и [окружение Rust и Tauri](https://tauri.app/start/prerequisites/).

```bash
npm install
npm run dev:app        # фронтенд в браузере
npm run tauri:dev      # приложение в окне
npm run build:app      # сборка фронтенда → dist/app
npm run tauri:build    # установщик → src-tauri/target/release/bundle/nsis/
npm run typecheck:all  # проверка типов: сначала ядро отдельно, затем весь проект
npm test               # тесты с заглушкой вместо моста, Tauri не нужен
```

`npm run tauri:build` подписывает пакет обновления, поэтому ему нужны переменные окружения `TAURI_SIGNING_PRIVATE_KEY` и `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`. Свою пару ключей можно создать командой `npm run tauri signer generate`.

Код разделён на слои: `src/shared/` — ядро (API, данные, кэш, мост к платформе), `src/app/` — экраны, компоненты и роутер, `src-tauri/` — нативная часть на Rust. Ядро ничего не знает об остальном приложении. Это проверяет `npm run typecheck:shared`: он собирает ядро без каталога `src/app` и падает, если ядро что-то импортирует оттуда.

## Выпуск

Релиз запускается тегом вида `app-3.0.0`. Сборка на `windows-latest` сверяет номер версии в теге с `package.json`, компилирует Rust, собирает установщик, подписывает обновление и публикует рядом `latest.json`. Описание релиза берётся из верхнего раздела `CHANGELOG.md`.

## Источники данных

| Источник | Для чего |
| :--- | :--- |
| `graphql.anilist.co` | данные и списки AniList |
| `shikimori.rip`, `shikimori.io` | русские названия, описания, персонажи, франшизы (зеркала одного сервиса, опрашиваются по очереди) |
| `smotret-anime.online`, `anime365.ru` | названия и описания (запасной источник anime365) |
| `anilibria.top`, `kodik-api.com` | прямые ссылки на видео для встроенного плеера |
| `graphql.animethemes.moe` | опенинги и эндинги |
| `cloud-api.yandex.net` | облачная копия списка: только по кнопке и только с вашей авторизацией |
| `github.com` | манифест обновлений и готовые данные (`foulnike/animori-data`) |

Все запросы отправляет сама программа. Ваши данные не передаются на сторонние серверы: токен и настройки остаются на вашем компьютере, кэш тоже локальный. Облачная копия сохраняется только на ваш собственный диск и только когда вы нажмёте кнопку. Как собираются готовые данные — в [`docs/DATA.md`](docs/DATA.md).
